# IPL Data Analysis Project

## Overview

This project analyzes IPL match data to uncover valuable insights related to match outcomes, scoring patterns, and player performance. The objective is to use data analysis techniques to identify important trends and patterns across IPL seasons.

---

## Objectives

* Analyze toss impact on match results
* Study phase-wise scoring patterns
* Identify top-performing batters and bowlers

---

## Tech Stack

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Key Insights

* Toss advantage had minimal impact on overall match outcomes.
* Death overs had the strongest influence on winning matches.
* Player performance analysis highlighted the most consistent performers across seasons.
