# IPL Data Analysis Project 

 #Objective
This project analyzes IPL match data to identify:
- Toss impact on match results
- Phase-wise scoring patterns
- Top batters and bowlers

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Toss advantage had minimal impact on IPL results.
- Death overs showed the strongest relationship with winning matches.
- Top player analysis highlighted the most consistent performers across seasons.
